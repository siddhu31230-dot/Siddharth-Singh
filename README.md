## 🌐 Running Locally

### Option 1: Open in Browser
Double-click `index.html` or run:
```bash
open index.html
```

### Option 2: Local HTTP Server (Python)
```bash
python3 -m http.server 8085
```
Then visit: `http://localhost:8085`
