GoDuet — Hyper-Local Campus Logistics

✕
GoDuet is a hyper-local campus food delivery platform designed to resolve the notorious "last 500 meters" problem for university students, late-night dormitory cravings, and campus cafeterias.

1. Spatial K-Means Batching Engine

Traditional aggregators treat every dormitory order as an isolated journey. GoDuet aggregates active student carts within 300-second rolling time windows and clusters deliveries going to identical hostel quads. A single student peer-courier fulfills up to 5 orders simultaneously, slashing per-delivery transit overhead by 68%.

2. Peer-to-Peer Verified Courier Economy

Verified student couriers walking back from classes or campus cafes claim batched delivery routes heading directly toward their own dormitory quads. This model eliminates delivery vehicle emissions on campus walkways and creates flexible on-campus student earning opportunities.

3. Architecture & Real-Time Telemetry

  • Frontend: Next.js 14 App Router, TypeScript, Tailwind CSS, Service Workers.
  • Backend: Node.js, WebSocket event streams, Redis Pub/Sub for real-time courier telemetry.
  • Database: PostgreSQL with PostGIS extensions for spatial quad polygon lookups.

AI SYSTEM · PRODUCTION PROTOTYPE

VOICEPRINT — Low-Latency Voice AI

✕
VOICEPRINT is an end-to-end conversational voice intelligence assistant combining acoustic speaker biometric verification with sub-300ms speech synthesis.

1. Sub-300ms Latency Pipeline

Traditional voice assistants experience 1.5–3.0s latency delays. VOICEPRINT streams raw audio chunks via WebSockets directly into fine-tuned Whisper STT models, while an asynchronous non-autoregressive acoustic vocoder begins synthesized audio playback before text generation finishes.

2. Speaker Biometric Verification

Protects private personal requests using 192-dimensional d-vector acoustic embeddings extracted directly from the user's vocal tract characteristics. Prevents unauthorized ambient voices or background noise from triggering personal assistant workflows.

3. Tech Stack

  • Python, PyTorch, Whisper STT, FastAPI, WebSockets, HiFi-GAN Vocoder, LangChain, ChromaDB.

CYBERSECURITY · PRODUCTION READY

Private Wellness Check-In — Cryptographic Health

✕
Private Wellness Check-In is a zero-knowledge mental health platform engineered for university dormitories, ensuring students can request counseling or medical help with mathematically guaranteed anonymity.

1. Zero-Knowledge Blind Signature Architecture

Student roll numbers and identifying metadata are salted and hashed client-side using the Web Crypto API prior to transmission. Even database administrators and campus authorities cannot reverse-engineer student identities from wellness logs.

2. Confidential Escalation Protocol

When high-risk sentiment triggers are detected, the system generates an anonymous single-use cryptographic token allowing students to interface directly with licensed counselors via encrypted end-to-end messaging channels.

3. Tech Stack

  • TypeScript, React, Node.js, Web Crypto API, PostgreSQL, Docker, End-to-End Encryption.

ROBOTICS & IOT · CONCEPT DESIGN

CampusFlow — Autonomous Rover Concept

✕
CampusFlow is an autonomous ground rover concept designed to navigate university pedestrian walkways, delivering packages and meals directly between campus facilities.

1. Perception & Navigation Stack

Powered by ROS 2 (Robot Operating System) with 2D LiDAR SLAM (Cartographer) and stereo depth cameras for dynamic obstacle avoidance in dense pedestrian campus environments.

2. Modular Dual OTP Payload Pod

Dual-compartment electronically actuated locker pod with thermal insulation. Students receive a one-time 4-digit code on their phones to authenticate and unlock their specific payload upon rover arrival.

3. Simulation Stack

  • ROS 2, Python, C++, Gazebo Simulation, RViz, OpenCV, Microcontroller Telemetry.
